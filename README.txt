Cách dùng:
1. Giữ nguyên thư mục assets/ hiện tại của bạn.
2. Sao lưu bộ code cũ.
3. Chép 7 file trên vào thư mục dự án (cùng cấp với assets/).
4. Mở index.html bằng Live Server.
